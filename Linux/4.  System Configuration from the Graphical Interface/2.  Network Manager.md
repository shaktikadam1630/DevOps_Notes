# Network Manager

This module covers how Linux handles network configuration graphically — through **Network Manager**, the tool behind wired, wireless, mobile broadband, and VPN connections on virtually every modern distribution.

---

## 1. Network Configuration

Every Linux distribution stores network configuration in files on disk, but the format and location vary between distributions. Editing them manually requires solid networking knowledge and distro-specific syntax — experienced administrators do work directly with these files, but it's not practical for everyday use.

**Network Manager** solves this: a consistent, graphical interface for managing connections across all major distributions, regardless of what's happening at the file level underneath.

![Network Manager — Connection Types](https://github.com/shaktikadam1630/DevOps_Notes/blob/main/Linux/images/network-manager-connection-types.png?raw=true)

Network Manager handles the full range of connections a desktop or laptop user is likely to need: **wired Ethernet, Wi-Fi, mobile broadband, and VPN**. It also manages connection profiles — storing settings for networks you've connected to before, so they reconnect automatically when available.

**Example:** For the vast majority of users, Network Manager should be the *only* tool you ever need for networking — manual config file editing is reserved for advanced server scenarios, covered later in this series.

> **Note:** For terminal users, Network Manager also includes `nmcli` — a powerful command-line tool offering the same functionality without a GUI.

## 2. Wired and Wireless Connections

### Wired Connections

Wired Ethernet is the simplest to manage — typically **zero manual setup**. Plug in a cable, and Network Manager detects it and configures it via **DHCP (Dynamic Host Configuration Protocol)**, the standard mechanism a router uses to automatically assign your IP address, subnet mask, default gateway, and DNS servers. This is identical to how wired connections work on Windows and macOS.

**Manual (static IP) setup**, if your network requires it:
1. Open **Settings → Network**
2. Locate your wired connection, click the **gear icon**
3. In the **IPv4/IPv6** tabs, switch from **Automatic (DHCP)** to **Manual**
4. Enter the IP address, subnet mask, gateway, and DNS server

You can also view/change the **MAC address** in the same settings panel — a unique 12-character hex identifier (e.g., `00:1A:2B:3C:4D:5E`) assigned to every network card, used by routers/switches to identify devices on the local network.

**Example:** Changing a MAC address is occasionally useful for troubleshooting, or on networks that restrict access based on a device's MAC address — some public/campus Wi-Fi setups filter by MAC.

### Wireless (Wi-Fi) Connections

Wi-Fi requires a brief manual step the first time you connect to a new network, then reconnects automatically thereafter.

**Connecting on any current GNOME-based distribution:**
1. Click the **system menu** (top-right corner) to open the quick-access panel
2. Select the **Wi-Fi section** to expand it — shows nearby networks (SSID + signal strength)
3. If Wi-Fi hardware is present but off, a toggle at the top turns it on
4. Select the network name → if open, connects immediately; if password-protected (padlock icon), enter the password and click **Connect**

By default, the password saves to your system keyring and the network is added to your known connections — future visits reconnect automatically without prompting again.

**Example:** Walking into a coffee shop you've visited before, your laptop reconnects to their Wi-Fi the moment it's in range — no re-entering the password, because Network Manager already remembered it from last time.

> **Note:** The visual layout of the Wi-Fi panel differs slightly between Ubuntu, Fedora, and openSUSE, but the underlying steps are identical — they all use Network Manager under the hood.

## 3. Managing Network Settings

### Mobile Broadband

When a mobile broadband device (USB cellular modem, tethered phone) connects, Network Manager detects it and launches a **setup wizard** guiding you through carrier selection and connection details. Once configured, the profile saves and connects automatically each time the device attaches.

### VPN Connections

Network Manager supports the most widely used VPN protocols:

| Protocol | Notes |
|---|---|
| **OpenVPN** | The most widely deployed open source VPN solution |
| **IPSec** | Standard protocol suite for encrypted IP communications, common in enterprise |
| **Cisco OpenConnect** | Compatible with official Cisco AnyConnect and its open source equivalent |
| **Microsoft PPTP** | For compatibility with older Windows-based VPN infrastructure |
| **WireGuard** | Modern, high-performance — built directly into the Linux kernel since 5.6, avoiding user-space/kernel-space overhead other VPNs incur |

**Adding a VPN connection:**
1. Go to **Settings → Network**, scroll to the **VPN** section
2. Click **+**, select your VPN type
3. Enter connection details from your VPN provider/administrator
4. Save the profile

Once added, toggle the VPN on/off from the system menu — on GNOME 43+, this lives in the **Quick Settings panel** (the pill-shaped buttons top-right).

> **Plugin note:** VPN support comes through protocol-specific plugins, which aren't always installed by default. If your VPN type doesn't appear when adding a connection, install the matching plugin — e.g., `network-manager-openvpn` on Ubuntu, or `NetworkManager-openvpn` on Fedora.

**Example:** A remote employee connecting to their company's VPN each morning just clicks the VPN toggle in Quick Settings — Network Manager handles the OpenVPN or IPSec handshake behind the scenes using the profile saved during initial setup.

## Hands-On: Lab — Exploring Your Network Configuration

**Objective:** Identify your current network configuration and explore available settings through Network Manager — no changes required, just observation.

1. **Open Network Manager** — click the system menu (top-right). The icon reflects your connection type: bars = wireless, a plug/arrow = wired Ethernet. Both may show if both are active.

2. **Identify your connection type** — check for a **Wired Connected** indicator, a **Wi-Fi** entry with a network name, or both. (Ubuntu shows wired/wireless as separate sections; Fedora/openSUSE similar, styled slightly differently.)

3. **View available wireless networks** (if applicable) — expand the Wi-Fi section to see nearby networks, signal strength, and which ones are password-protected (padlock icon) vs. open.

4. **Review your connection details** — open **Wi-Fi Settings** or **Wired Settings**, click the gear icon on your active connection, then the **Details** tab. Note:

| Field | What It Tells You |
|---|---|
| **IP address** | Your machine's address on the local network (often `192.168.x.x` or `10.x.x.x`) |
| **Default gateway** | Your router's address — the path your traffic takes to reach the internet |
| **DNS server** | The server your system queries to resolve domain names into IP addresses |
| **Configuration method** | **Automatic (DHCP)** — assigned by your router — or **Manual** — entered by a user/admin |

**Example:** Checking these details on a home network typically shows an IP like `192.168.1.42`, a gateway of `192.168.1.1` (your router), and DHCP as the configuration method — confirming your router is handling everything automatically, exactly as expected for a standard home setup.

## The Full Picture

**Network Manager** is the single graphical tool behind every connection type you'll encounter day to day — wired connections that "just work" via DHCP, Wi-Fi that remembers passwords after the first connect, mobile broadband guided by a setup wizard, and VPNs supporting everything from OpenVPN to the kernel-native WireGuard. Everything lives in one consistent place — **Settings → Network** or the Quick Settings panel — regardless of which distribution you're running or what config file format sits underneath. For virtually all everyday use, this is the only networking tool you'll ever need to open.
